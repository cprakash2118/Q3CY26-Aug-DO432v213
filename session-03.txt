 What is "MultiClusterHub" ?
 This is the main custom resource (CR) that instruct the RHACM operator to:-
 - Intsall 
 - Configure 
 - Manage and 
 - Upgrade
 All RHACM hub components.
 
 Example:-
 - INstalling ACM operator install the controller.
 - Creating "MultiClusterHub" tells the controller to build the actual ACM HUB.
 
Componets & Pupose (Understading w.r.t RHACM operator and MultiClusterHub).
- RHACM Operator - Watches and amanges RHACM resources.
- MultiClusterHub CR - Requets deployment of the complete RHACM HUB.
- HUB Cluster - Central cluster used to manage other "managed cluster".
- Managed Cluster - Remote OpenShift/kubernetes cluster managed by the HUB cluster.
  FYI- https://www.cncf.io/training/certification/software-conformance/
- klusterlet - Node agent running on each managed cluster.
  

- When RHACM installed on one of the OpenShift cluster.
  - Default namespace for ACM (HUB cluster) 
    - open-cluster-management
    - open-clutser-management-hub
	- open-cluster-management-global-set
	
  - Default namespace for "local-cluster/managed-cluster".
    - open-cluster-management-agent 
	- open-cluster-management-policies 
	- open-cluster-management-agent-addon
