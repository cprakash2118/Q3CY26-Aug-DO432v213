Task-05# Governance Policy:-
-----------

1- What is RHACM Governance?
Governance -> Control + Visibility + Enforcement
1-) Policy defination (What is allowed/required).
2-) Policy placement (Where it apply)
3-) Compliance reporting (WHo is compliant/ non compliant).
4-) Optional remediaion (auto-fix voilations).

All these points works across cluster.


2- Policy Based Governance Architecture.
HUB Cluster (CP - Control Plane):-
 - POlicy CRs are created only here (AT HUB cluster)
 - Policies are replicated to managed cluster.
 - compliance is agrregated back.
 
 
Managed cluster (Execution Plane):-
 - COntrollers evaluate policies 
 - Generate voilations
 - Optionally remediate 
 
3- COre Governance components:-
 3.1- Governance Dashboard:-
      - GUI for -> Creating policies; viewing voilations; Enabling/disabling enforcement.
      - Filters by -> cluster, namespace,severity and remediaion state.
   
 3.2- POlicy Controllers:-
     COntrollers watch policy CRs, evaluate compliants and gererate events.
	 CRD-based system built on:-
	 - policy 
	 - Placement 
	 - placementBinding 
	 - policySet 

Policy lifecycle management:-
1-) Create policy on HUB cluster.
2-) Placement selects cluster 
3-) POlicy Propagator (replicates policy to managed cluster).
4-) Managed cluster controllers evaluate.

5-)Violation/Event generated

6-) Status sync back to HUB cluster 
7-) Dashboard show/display complainance 
8-) Optional remediaion happens.
