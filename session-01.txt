###Point-02# Classroom Environment (Consider ACM onboarding situation).
1-) Users details:-
    Login to VMs/Servers 
	- student/student (sudo access)
	- root/redhat
	
	Login to OCP clusters
	- admin/redhatocp      (cluster-admin ; it's same as root account w.r.t Linux)
	- developer/developer     
	FYI- 
	- OAuth (Identity Broker on behalf of OpenShift) sync with IdPs and enabled token based authentication.
	- Both accounts (admin & developer) belongs to LDAP.

    API URL:- 
	Cluster-01 -> https://api.ocp4.example.com:6443 
	Cluster-02 -> https://api.ocp4-mng.example.com:6443 
   
     Example:-
	 $ oc login -u admin -p redhatocp https://api.ocp4.example.com:6443 
	 $ oc login --token=kjshdkjsahdkj --server=https://api.ocp4.example.com:6443 
	 FYI- Token = userName + Passowrd 

    c1-Web Console -> https://console-openshift-console.apps.ocp4.example.com 
    c2-Web Console -> https://console-openshift-console.apps.ocp4-mng.example.com
