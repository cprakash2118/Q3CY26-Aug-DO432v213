- Installed ACM on specific OpenShift cluster (That cluster become HUB cluster).
- ACM also managed HUB cluster as managed cluster (local-cluster).
- Any k8s cluster when imported/registered with HUB cluster, multiple agents deployed (example - klusterlet)
- HUB cluster services belongs to below namespaces.
  - open-cluster-management 
  - open-cluster-management-hub 
  - open-cluster-management-global-set 

- Managed cluster services belongs to below namespaces.
  - open-cluster-management-agent 
  - open-cluster-management-policy 
  - open-cluster-management-agent-addon

- ClusterSet:- Logical grouping of the cluster (Under ACM). 
- One cluster can not be part of multiple clusterSet.
- While onboarding new k8s cluster to HUB cluster, bydefault cluster be part of "default" clusterSet.
- While onboarding new k8s cluster to HUB cluster, bydefault cluster also part of "global" clusterset.
- When create new clusterSet or adding cluster to other clusterSet then it transfer the clusterSet owenership.

ClusterSet (by default)
global  - any cluster imported/created and managed by HUB cluster will be part of global.
default - while importing cluster if you have not define the clusterSet then cluster moved to default.

rosa-clusterSet  - c1,c2,c3 
cloud-clusterSet - c1,c4,c5
